# 🚀 Enterprise HR Portal

A Full Stack Employee Management System built using Spring Boot, React, and MySQL.

---

## 📌 Tech Stack

### Backend
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL

### Frontend
- React
- React Router
- Axios
- Bootstrap 5
- Vite

### Database
- MySQL

---

## ✨ Features

- Employee Dashboard
- Add Employee
- View Employee List
- Update Employee
- Delete Employee
- Search Employee
- REST API
- Responsive UI

## ▶️ Run Backend

```bash
cd backend
mvn spring-boot:run
```

Backend URL

```
http://localhost:8080
```

---

## ▶️ Run Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend URL

```
http://localhost:5173
```
